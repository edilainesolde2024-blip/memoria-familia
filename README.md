# 🧠 Jogo da Memória - Memórias Afetivas da Família 📸✨

## 💙 Sobre o Projeto

Este projeto consiste em um **Jogo da Memória personalizado**, desenvolvido utilizando **HTML, CSS e JavaScript**, onde as cartas utilizam fotografias reais da família.

A ideia principal da criação foi transformar um simples jogo em uma experiência de **memória afetiva**, reunindo momentos especiais, pessoas importantes e lembranças que fazem parte da história da família.

Cada par encontrado representa uma recordação, tornando a interação com o jogo uma forma divertida de reviver momentos especiais.

---

## 🎯 Objetivo

Criar uma aplicação web simples e interativa que, além de aplicar conceitos de desenvolvimento Front-End, também tenha um significado pessoal:

- Guardar lembranças através das fotografias;
- Valorizar momentos familiares;
- Criar uma experiência divertida para todas as idades;
- Unir tecnologia e memória afetiva.

---

## 🚀 Tecnologias Utilizadas

O projeto foi desenvolvido utilizando:

- 🌐 **HTML5**  
  Estrutura da página e organização dos elementos.

- 🎨 **CSS3**  
  Estilização do jogo, criação do layout, efeitos visuais e animações das cartas.

- ⚙️ **JavaScript**  
  Responsável pela lógica do jogo, embaralhamento das cartas, comparação dos pares e controle da pontuação.
